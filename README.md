# NiseDomainDame (NDD)

[English](README.en.md)

*ニセドメイン、ダメ、ゼッタイ。*

見た目が本物そっくりな偽装ドメインの、実際のpunycodeを表示します。ホモグラフ攻撃によるフィッシングサイトを、開く前に警告するChrome拡張です。

## 機能

- **危険なドメインを読み込み前にブロック**：短縮URLなどのリダイレクト経由でも止めます
- **ツールバーのバッジ**：危険なら赤の `!`、国際化ドメイン（IDN）ならオレンジの `IDN` を表示します
- **ポップアップ**：punycode、Unicode表記、検出理由を表示します
- **許可リスト**：信頼できるサイトを登録できます

## 検出する条件

- 1つのラベル内で文字種が混在している（例：キリル文字＋ラテン文字の `аpple.com`）
- ラテン文字に見えるキリル文字・ギリシャ文字だけで構成されている（`аррӏе.com`）
- 有名サービスに見た目が酷似している（Google、Apple、PayPal、Amazon、国内主要銀行など）
- punycodeとして不正な形式になっている

`日本語.jp` や `münchen.de` のような正当なIDNは、`IDN` バッジが付くだけでブロックされません。

## インストール

1. このリポジトリをダウンロードまたはクローンします
2. `chrome://extensions` を開き、**デベロッパーモード**をオンにします
3. **パッケージ化されていない拡張機能を読み込む**で、このフォルダを選びます

## 動作確認

テスト用に予約されたドメインは実在しないので、安全に試せます。必ず `https://` から入力してください。

| URL | 結果 |
|---|---|
| `https://xn--pple-43d.test/`（аpple.test） | 警告ページ |
| `https://xn--80ak6aa92e.invalid/`（аррӏе.invalid） | 警告ページ |
| `https://httpbin.org/redirect-to?url=https://xn--pple-43d.test/` | リダイレクト後に警告ページ |
| `https://xn--mnchen-3ya.test/`（münchen.test） | `IDN` バッジのみ |

## プライバシー

すべての処理はブラウザ内で完結します。外部へのデータ送信は一切なく、サイトへのアクセス権限もないため、ページの内容は読み取れません。許可リストはこの端末内にだけ保存されます。

## 制限事項

- Chromeの仕様上、拡張はURL欄そのものを書き換えられません。そのため、punycodeはバッジ・ポップアップ・警告ページで表示します。
- リダイレクトの場合、警告ページに切り替わる前に偽装ページが一瞬読み込まれることがあります。
- iframe内のページは判定しません。

## 公式の配布元

公式の配布元はこのリポジトリだけです。他の場所で配布されている改造版はインストールしないでください。
